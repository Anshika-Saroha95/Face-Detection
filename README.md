# Face Detection System

## About the Project
This is a Python-based Face Detection System developed using OpenCV. It uses computer vision techniques and the Haar Cascade Classifier to detect human faces in real time through a webcam.

## Technologies Used
- Python
- OpenCV (cv2)
- Haar Cascade Classifier

## Features
- Real-time face detection.
- Detects multiple faces in a single frame.
- Uses webcam for live video input.
- Displays rectangular bounding boxes around detected faces.

## Installation

**1. Clone the repository**

```bash
git clone https://github.com/Anshika-Saroha95/Face-Detection.git
```

**2. Navigate to the project directory**

```bash
cd Face-Detection
```

**3. Install OpenCV**

```bash
pip install opencv-python
```

**4. Run the project**

```bash
python filename.py
```

Replace `filename.py` with your actual Python file name.

## How It Works
1. Captures live video through the webcam.
2. Converts video frames into grayscale images.
3. Uses the Haar Cascade Classifier to detect faces.
4. Draws rectangular boxes around detected faces.
